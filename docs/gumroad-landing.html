How it works

Three steps. About five minutes.

  1. Deploy

    Click the deploy button, sign into GitHub and Vercel — both free — and paste three values: your license key, your Kie.ai API key, and a random secret you make up. The build takes about three minutes.

  2. Prove it works

    Open your private dashboard and hit the test-image button. If an image comes back, your Kie.ai key is wired up correctly — before you touch GoHighLevel at all.

  3. Connect to GHL

    In GoHighLevel: Ask AI → the + icon → Manage Connectors → + Add custom MCP. Paste your MCP URL, click Add MCP, then ask your agent for an image.

FAQ

Straight answers

Do you resell me Kie.ai credits?

No. You pay Kie.ai directly for what you generate. This product doesn't resell you credits and never touches your key — it lives in your own Vercel account.

Is Vercel's free tier enough to run this?

Vercel's free tier runs this fine, but their Hobby plan terms are non-commercial. Running it for clients means Vercel Pro, at $20/month.

Can one license cover several clients or brands?

One Full license covers one deployment, one GHL location. Running clients? FreshGen Link Agency ($147) serves every sub-account from one deployment and takes your brand.

Is this a general-purpose AI toolbox?

No, on purpose. Images and video only — this isn't a general-purpose AI toolbox.

Do I need to know how to code?

No. You click the deploy button, paste a few values, and copy one URL into GHL. If you can fill out a form, you can set this up.

What happens if my license key is missing?

Generation switches off. The informational tools still work, but generate_image, generate_video, and save_to_media_library return a not-activated message until you add a valid license key in Vercel and redeploy.
