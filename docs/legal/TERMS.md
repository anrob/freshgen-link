## 2. What FreshGen Link is

FreshGen Link is a self-hosted MCP (Model Context Protocol) server — a small web application — that lets GoHighLevel ("**GHL**") AI agents generate images and video through Kie.ai.

**FreshGen Link is self-hosted. You operate your own copy.** When you deploy it, the code is copied into your own GitHub account and deployed to your own Vercel account (your "**Deployment**").
